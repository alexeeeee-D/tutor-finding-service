# Бизнес-домен. Сервис для поиска репетиторов

**Вариант № 20** (группа 5130904/40101)

## О задаче

Задачей является разработка сервиса, ориентированного на подбор учеников
репетитору и репетитора ученику.

## Формула варианта СМО

`ИБ — ИЗ2 — ПЗ1 — Д10З2 — Д10О4 — Д2П2 — Д2Б1 — ОР1 — ОД2`

| Код | Описание |
|---|---|
| ИБ | Бесконечный источник |
| ИЗ2 | Равномерный закон распределения интервалов поступления |
| ПЗ1 | Экспоненциальный закон обслуживания |
| Д10З2 | Буфер в порядке поступления (FIFO), запись в первое свободное место |
| Д10О4 | Отказ последней поступившей заявке при переполнении буфера |
| Д2П2 | Выбор прибора по кольцу |
| Д2Б1 | Выбор заявки FIFO (первым пришёл — первым обслужен) |
| ОР1 | Автоматический режим — сводная таблица статистики |
| ОД2 | Пошаговый режим — схема модели и состояние системы |
