# Маппинг домена на элементы СМО

## Таблица соответствий

| Элемент СМО | Сущность бизнес-домена | Назначение |
|---|---|---|
| **Источник(ИБ, ИЗ2)** | Ученик (или родитель) | Непрерывно формирует заявки на подбор репетитора и передаёт их в систему обработки. Каждый ученик может оставить несколько заявок за время работы платформы. |
| **Заявка** | Запрос на подбор репетитора | Единица информации, которая должна быть принята системой. Содержит: предмет, класс, цель занятий, предпочтения по времени. Ожидает в буфере и обрабатывается модератором. |
| **Буферная память(Д10З2)** | Очередь заявок на обработку | Временно хранит заявки, ожидающие обработки, если они не могут быть немедленно переданы модератору. Линейная очередь: заявки становятся в порядке поступления, при освобождении места — сдвиг. |
| **Прибор(ПЗ1)** | Алгоритм подбора (или модератор-человек) | Выполняет обработку заявки: анализирует требования ученика, подбирает подходящих репетиторов, связывает стороны. Время обработки — экспоненциальное. |
| **Диспетчер постановки(Д10З2)** | Компонент приёма и размещения заявок | Размещает новую заявку в буфере в порядке поступления (Д10З2): заявка занимает первое свободное место, начиная с начала очереди. При освобождении места все заявки сдвигаются. При переполнении буфера применяет дисциплину отказа Д10О4 — выбивает последнюю поступившую заявку. |
| **Диспетчер выбора(Д2Б1)** | Планировщик обработки | Выбирает из буфера одну заявку по FIFO (Д2Б1): выбирается заявка, которая дольше всех простояла в очереди. Затем передаёт заявку свободному модератору, выбранному по кольцу (Д2П2). |
| **Отказ(Д10О4)** | Уведомление об отклонении | При переполнении буфера удаляется последняя поступившая заявка (самая новая), независимо от положения указателя; новая заявка занимает её место. Ученик получает уведомление: «Система перегружена, попробуйте позже». |
| **Обслуживание** | Обработка заявки модератором, алгоритмом или ИИ-агентом | Алгоритм анализирует заявку (предмет, класс, цель), подбирает подходящих репетиторов из базы, формирует рекомендации. После этого заявка покидает моделируемую систему. |
| **Выход из системы** | Обработанная или отклонённая заявка | Заявка покидает систему после успешного подбора репетитора либо в результате отказа (выбивания из буфера). |
