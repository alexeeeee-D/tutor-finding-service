# Маппинг домена на элементы СМО

**Сервис для репетиторов**

**Вариант № 20** (группа 5130904/40101)

## Таблица соответствий

| Элемент СМО | Сущность бизнес-домена | Назначение |
|---|---|---|
| **Источник** | Ученик (или родитель) | Непрерывно формирует заявки на подбор репетитора и передаёт их в систему обработки. Каждый ученик может оставить несколько заявок за время работы платформы. |
| **Заявка** | Запрос на подбор репетитора | Единица информации, которая должна быть принята системой. Содержит: предмет, класс, цель занятий, предпочтения по времени. Ожидает в буфере и обрабатывается модератором. |
| **Буферная память** | Очередь заявок на обработку | Временно хранит заявки, ожидающие обработки, если они не могут быть немедленно переданы модератору. Линейная очередь: заявки становятся в порядке поступления, при освобождении места — сдвиг. |
| **Прибор** | Алгоритм подбора (или модератор-человек) | Выполняет обработку заявки: анализирует требования ученика, подбирает подходящих репетиторов, связывает стороны. Время обработки — экспоненциальное. |
| **Диспетчер постановки** | Компонент приёма и размещения заявок | Размещает новую заявку в буфере в порядке поступления (Д10З2): заявка занимает первое свободное место, начиная с начала очереди. При освобождении места все заявки сдвигаются. При переполнении буфера применяет дисциплину отказа Д10О4 — выбивает последнюю поступившую заявку. |
| **Диспетчер выбора** | Планировщик обработки | Выбирает из буфера одну заявку по FIFO (Д2Б1): выбирается заявка, которая дольше всех простояла в очереди. Затем передаёт заявку свободному модератору, выбранному по кольцу (Д2П2). |
| **Отказ** | Уведомление об отклонении | При переполнении буфера удаляется последняя поступившая заявка (самая новая), независимо от положения указателя; новая заявка занимает её место. Ученик получает уведомление: «Система перегружена, попробуйте позже». |
| **Обслуживание** | Обработка заявки модератором, алгоритмом или ИИ-агентом | Алгоритм анализирует заявку (предмет, класс, цель), подбирает подходящих репетиторов из базы, формирует рекомендации. После этого заявка покидает моделируемую систему. |
| **Выход из системы** | Обработанная или отклонённая заявка | Заявка покидает систему после успешного подбора репетитора либо в результате отказа (выбивания из буфера). |

## Связь с формулой варианта

`ИБ — ИЗ2 — ПЗ1 — Д10З2 — Д10О4 — Д2П2 — Д2Б1 — ОР1 — ОД2`

| Код | Элемент СМО из таблицы |
|---|---|
| ИБ | Источник (ученик) |
| ИЗ2 | Равномерный закон поступления заявок |
| ПЗ1 | Прибор (экспоненциальное обслуживание) |
| Д10З2 | Буферная память (FIFO-очередь) |
| Д10О4 | Отказ (последней поступившей) |
| Д2П2 | Диспетчер выбора — выбор прибора по кольцу |
| Д2Б1 | Диспетчер выбора — выбор заявки FIFO |
| ОР1 | Автоматический режим (сводная таблица) |
| ОД2 | Пошаговый режим (схема и состояние системы) |
